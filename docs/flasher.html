ehRadio Flasher

These firmwares are meant for pre-built radios. They must match the device's hardware configuration. Check the Releases.

Step 1 · Flash the Firmware

This step only writes the firmware. Nothing else happens: no Wi-Fi "improv" prompt, no tab that stays open waiting for the device. When the last block is written you get a success or a failure and that is the end of it.

First install or after erasing: the radio formats its internal storage on first boot. Expect about 3 to 5 minutes on a 16MB board and up to 8 minutes on a 32MB board. Do not unplug while this is happening.

Step 2 · Set Up Wi-Fi

Connect over USB and send the Wi-Fi credentials to a radio that is sitting in AP/Improv mode. This part uses the Improv serial protocol, so it needs Chrome, Edge or Brave (Firefox and Safari do not expose the serial port).

A radio that has just been flashed will not answer until it has finished its first boot. Keep this page open: the button below waits and shows a running timer, up to 10 minutes. The timer is the patience message.

Step 3 · Device Logs

Open the serial console of a running radio. Useful to read the IP address it was given, or to see what happens during that long first boot. Close the log before flashing or setting up Wi-Fi, because only one of them can hold the serial port at a time.

Good to Know

  • Flash firmware with Step 1, then set up Wi-Fi with Step 2. They are deliberately separate.
  • The radio restarts once it accepts the credentials. The serial connection drops at that moment: that is the expected end of the flow, not an error.
  • An already-configured radio does not listen for Improv again until it falls back to AP mode, so Step 2 only works on a radio in AP/Improv mode.
  • There are 5 Wi-Fi slots. A new network is appended until the list is full, after which slot 5 is replaced, exactly like the WebUI does it.
  • No luck here? Try the ESP Web Tools flasher.
