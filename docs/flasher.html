ehRadio Flasher

These firmwares are meant for pre-built radios. They must match the device's hardware configuration. Check the Releases.

Step 1 · Flash the Firmware

This step writes the firmware. It may be used to upgrade existing firmware.

Full install will clear the entire flash, including settings and files. If this is checked, the WebUI files will also be installed. This is recommended for first-time flashes or fresh installs.

Upgrading an existing ehRadio? Do not check full reinstall. WebUI files will be updated after reboot and your settings and playlists will be intact.

On a first boot, the filesystem will be checked. If it is not valid, it will be formatted before Wi-fi is configured. This can take some time. After connecting to to the network, the WebUI files will then be downloaded.

Step 2 · Set Up Wi-Fi (Improv)

When the radio is in AP/Improv Mode, this will send Wi-fi provisioning data so it can connect to your local network.

This uses the Improv serial protocol, so it needs Chrome, Edge, or Brave. Firefox and Safari do not expose the serial port.

Step 3 · Device Logs

Open the serial console of a running radio. Useful to read the IP address it was given, or to see what happens during that long first boot. Close the log before flashing or setting up Wi-Fi, because only one of them can hold the serial port at a time.
