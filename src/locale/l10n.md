Notes
- `weatherLang` values are taken from each locale's `weatherLang[]` definition in `locale/displayL10n_*.h`.
- If a `weatherLang` is set to `en` it can mean either OpenWeather does not provide that language code or the locale currently falls back to English.
- To change a locale's OpenWeather language code, edit the respective `displayL10n_*.h` and update `weatherLang[]`.  Remember to update this table if you add new locales.
